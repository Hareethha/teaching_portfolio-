# Hareethha V. - Teaching Portfolio

A static, recruiter-friendly teaching portfolio. It includes anonymised teaching notes and practice materials plus links to selected GitHub projects.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `teaching-portfolio`.
2. Upload everything in this folder **without changing the folder structure**.
3. Commit the files to the `main` branch.
4. Open **Settings -> Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. GitHub will provide a URL similar to:
   `https://hareethha.github.io/teaching-portfolio/`

## Included portfolio copies

Student names have been removed from the worksheet/assessment PDFs. The handwritten note samples use selected pages with no student names visible.

## Easy edits

- Main text: `index.html`
- Styling: `styles.css`
- PDFs: `assets/pdfs/`
- Preview images: `assets/thumbs/`
